# website_project
A website project based on JavaScript Mastery. 

Idea is to replicate an Apple-style website with React, Three.js and GSAP and TailwindCSS. Later on include own content, but for now building according to tutorial.

Tutorial in question:
https://www.youtube.com/watch?v=DEeaT6FxEws&t

The tutorial was completed on Monday 12th of January 2026.

## Quick Start

### Prerequisites
- **Node.js** (Version 18 or higher)
- **npm** or **yarn**
- Web browser

### Installation

```bash
# Clone the repository
git clone https://github.com/jduong42/website_project.git
cd website_project

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:5173
